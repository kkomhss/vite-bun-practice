# Vite + Bun Practice

**Практическая работа по настройке современного фронтенд-проекта**

## О проекте

Данный проект создан в рамках изучения современных инструментов веб-разработки. Он демонстрирует настройку и использование связки Vite + Bun для быстрой разработки и сборки приложений.

## Стек технологий

- **Vite** — быстрый инструмент сборки
- **Bun** — JavaScript/TypeScript-рантайм и пакетный менеджер
- **TypeScript** — типизированный JavaScript
- **Vanilla** — чистый JavaScript (без фреймворков)

## Запуск проекта

```bash
# Установка зависимостей
bun install

# Запуск dev-сервера
bun run dev -- --host 0.0.0.0

# Сборка для продакшена
bun run build

# Просмотр собранного проекта
bun run preview -- --host 0.0.0.0
